# Validador de CPF - Validação de CPF em React

## Descrição

O **Validador de CPF** é uma aplicação simples construída com **React** e **Bootstrap**, com o objetivo de validar o CPF inserido pelo usuário. 

Este projeto foi desenvolvido para ser uma primeira experiência com validação de formulários e interação com o estado em React totalmente focada em fins didáticos.

## Funcionalidades

- **Validação em tempo real**: A aplicação faz a validação em tempo real do CPF inserido.
- **Validação de formato**: O CPF precisa ter exatamente 11 números (sem pontuação) para ser considerado válido.
- **Feedback visual**: A aplicação mostra o resultado caso o CPF seja válido ou não com ajuda da classe alert do Boostrap.

## Tecnologias Utilizadas

- React
- Vite
- Bootstrap
- JavaScript
